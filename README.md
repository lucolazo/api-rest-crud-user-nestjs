# Microservicio de Pagos (Stripe + NestJS)

Trabajo Práctico - Programación Avanzada (Licenciatura en Sistemas de Información)

## Requisitos previos

- Node.js instalado.
- Dependencias: ejecutar `npm install`.

## Configuración

1. Copiar el archivo `.env.template` a `.env` y rellenar las variables (`STRIPE_SECRET`, URLs, etc.).

## Ejecución

```bash
# Desarrollo
npm run start:dev
```
